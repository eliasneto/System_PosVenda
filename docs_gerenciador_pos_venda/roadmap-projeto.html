  • A migração inicial dos dados de Escola (2.622 registros) para o novo banco é obrigatória antes da v1 entrar em uso — execução única, ainda sem data marcada.
  • Prazo da v1 é apertado; qualquer atraso na pendência restante pressiona essa data primeiro.
